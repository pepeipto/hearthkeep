# Demo video storyboard

45 to 60 seconds, recorded in the real WoW Forever client on launch day with test characters. No real account names, guild names or chat.

## Recording setup

- OBS or similar, 1920x1080, 30 fps, game capture, no webcam.
- UI scale 1, English interface. Mouse cursor visible so clicks are clear.
- Record without audio and add captions, or add calm music that you have the right to redistribute (see CurseForge's music rule). Do not use unlicensed music.
- Keep the file under 100 MB if it will be uploaded; otherwise link it from the description as a video, not as a download.

## Scenes

| Time | On screen | Caption |
|---|---|---|
| 0:00-0:05 | Log in on a test character; the minimap button is visible | Hearthkeep keeps all your characters in one place |
| 0:05-0:12 | Type `/hk`; the window opens with five characters | One window for every character |
| 0:12-0:20 | Click the Level, then the Gold header; the order changes | Sort by any column |
| 0:20-0:27 | Click the realm button twice; the list and footer change | Filter by realm, with the total gold |
| 0:27-0:35 | Hover a row; the tooltip shows realm, zone and cooldowns | See cooldowns at a glance |
| 0:35-0:42 | Right-click a row, choose Hide; the row disappears | Hide the characters you do not need |
| 0:42-0:50 | Enter combat against a training dummy with the window open | Works in and out of combat |
| 0:50-0:57 | `/hk modules`, then `/hk disable Alts` and `/hk enable Alts` | Modular: turn features on or off |
| 0:57-1:00 | Title card: Hearthkeep, free and open source | Free, with the source code visible |
