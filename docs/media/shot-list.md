# Screenshot shot list

Real in-game captures only, taken in the WoW Forever client on launch day. The files in `mockups/` are design mockups and are not a substitute.

## Setup

- Use test characters, never a real account's characters. Create at least five across two realms, with different classes, levels and professions, so the list looks varied. Include one with no professions.
- Resolution 1920x1080 or higher, UI scale 1, interface in English for the main set and a second pass in Spanish.
- Hide anything personal: real character names, guild names, chat, friends list.
- Save as PNG. Name files `NN-short-description.png` in the order below.

## Shots

| # | State to capture | Notes |
|---|---|---|
| 01 | Window open with 5+ characters, sorted by level, all realms | The main gallery image |
| 02 | Same window sorted by gold (click the Gold header twice if needed) | Shows the sort arrow |
| 03 | Realm button on one realm | Footer total follows the filter |
| 04 | Right-click menu on a row (Hide / Delete) | Menu visible next to the row |
| 05 | Tooltip over a character with cooldowns | Realm, zone, cooldown remaining |
| 06 | Empty state | Delete test characters, or use a fresh profile |
| 07 | Window open in combat | Engage a target dummy so the character is visibly in combat, with the window open |
| 08 | Spanish client | Same as 01 |
| 09 | Minimap button | Zoomed on the minimap corner |
| 10 | `/hk modules` and `/hk debug` output in chat | Shows the diagnostics |

## After capturing

- Check no real account data is visible in any shot.
- Add a short caption to each in the CurseForge gallery that says what it shows.
- If an image is edited or enhanced with AI, add a clear note in the caption or the description that it is not an unmodified capture. Prefer unedited captures.
