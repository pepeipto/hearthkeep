## 4. Key decisions
- Default language English (large community); Spanish and German also; French later.
- Free forever in game: no ads, no donation requests in game. Donations only outside the game
  (Ko-fi / GitHub Sponsors; maybe CurseForge rewards). Paid "Pro" addon rejected (Blizzard
  policy bars premium editions); any paid services would live outside the game, later.
- Licensing (suite strategy): MIT, clean-room, write our own. DBM and Details! are "All Rights
  Reserved"; Naowh Forever too; Questie permits GPLv3 forks but the owner chose OUR OWN Quests.
  Record any reused third-party item in `docs/licenses.md` first.
- Packaging: an addon cannot install other addons in the game. Own addons ship in our zip.
  Third-party ones: installer fetches from official release pages on the player's machine, or
  bundle with the author's written permission (permission-request draft in the packaging
  study). Questie needs a second addon, **QuestieDB** (already added to the quests mode).
- Quests will be a step-by-step leveling guide (panel + arrow + auto-progress) with original
  routes and a **route recorder** (the owner plays, the addon writes the steps). Designed in
  `2026-11-16-hearthkeep-quests-design.md`. Not started.
- Target order of own addons: Modes, Bosses (notes), Quests, map/world, bags, loot tables,
  auctions, PvP; damage meter and boss alerts last (Forever hides combat data).
- Ideas from Naowh Forever to build our own version of: first-run profile presets
  (Minimal/Recommended), a home page with one button per module, a dungeon journal with
  loot and maps, a BiS list, QoL options (check each against policy).

## 5. Research facts (third-party sources; verify before relying)
- Forever carries the same addon restrictions as Midnight ("secret values"): no combat-log
  parsing, no realtime timers from combat. Blizzard's line: addons may change how information
  looks, not what the player acts on. Policy: addons must be free; paid guides are tolerated
  (RestedXP, Zygor-like) but not permitted; WoW China cracks down.
- Downloads: DBM ~636M, Details! ~370M, Questie ~210M, Auctionator ~205M (all-time classic line).
  WowUp and the CurseForge app install Forever addons; no one-click collection exists.
- Income reality: WeakAuras Patreon ~$500/month (undated), DBM ~3,000 patrons; hypothetical
  10,000 users x 1% x $3 = $300/month.
- Questie's own file `FOREVER_WORK_LEFT_TO_DO.md` shows even it has not validated Forever data.
